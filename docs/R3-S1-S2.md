# SMD Public · R3-S1/S2

Independent Nuxt 4 public application. Original seven public pages and dynamic category routes remain here.

## Build

```sh
npm install
npm run verify:contracts
npm run test:boundary
npm run typecheck
npm run build
```

Only `smd-public/` and its pinned `vendor/content-contracts/` artifact are needed. No dependency on the CMS source directory. `npm install` needs network access because Nuxt and Wrangler are not bundled. **No lockfile was fabricated in this bake**; run a real install and commit the generated lockfile before deployment approval.

## Cloudflare boundary

`wrangler.toml` binds `SMD_CORE` to `smd-core` named entrypoint `PublicSurface`. There are NO DB, R2 or Admin bindings in the public application. Production host, environment and Turnstile keys must be configured out of band. Staging binds to `smd-core-staging` only.

The public BFF retains `/api/render`, `/api/content`, `/api/inquiries`, `/api/bot/ask`, `/api/bot/webhook` and `/sitemap.xml`. It cannot forward inbound Access JWT. Signed legacy webhook forwards raw request bytes unmodified.

`SMD_DEV_FIXTURE_ONLY=1` requires a local dev runtime **without** Core binding. Normal dev requests consume live Core publication; missing Core or unknown publication fails closed.

**No public admin route** exists. Historical test scripts not yet ported to this split are retained as source-history, NOT automatically claimed as passing in the new runtime.

## Deploy hold

`wrangler deploy --env staging` needs environment bindings, known staging Core, tested Access/Turnstile policy and independent contract handshake. Production deployment is not automated by build.
